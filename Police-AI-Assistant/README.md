## Overview

This repository provides a clean scaffold for a Police AI Assistant platform built with:

- Frontend: Next.js 15, TypeScript, TailwindCSS, shadcn/ui
- Backend: FastAPI, Python 3.12
- Database: Supabase
- Vector Database: Qdrant
- LLM: Groq
- OCR: Gemini
- Agent Framework: LangGraph
