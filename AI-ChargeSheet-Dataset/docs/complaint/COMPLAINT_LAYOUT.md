# Complaint Document Layout

## Purpose
This document captures the complainant's formal written complaint and aligns it with the FIR narrative structure.

## Sections
- Header
- Complaint details
- Incident summary
- Complainant details
- Accused details
- Signature block

## Mandatory fields
- Complainant name
- Incident date
- Place of occurrence
- Narrative summary

## Optional fields
- Accused details
- Additional notes
